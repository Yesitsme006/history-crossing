# 历史交汇点 ⏳

> 同一地点，不同时空的故事在这里交织。

一个用故事串联历史的 Web 应用。搜索一个地点，就能看到不同时代的人在同一片土地上留下的足迹——周幽王、唐玄宗、蒋介石在 **华清池** 擦肩而过，崔颢、李白、革命军在 **黄鹤楼** 隔空对话。

## 技术栈

- **构建工具**: Vite
- **前端框架**: React 18 + TypeScript
- **样式方案**: Tailwind CSS 4
- **模糊搜索**: Fuse.js
- **部署**: 静态站点（Vercel / GitHub Pages）

## 快速开始

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 项目结构

```
src/
├── components/        # UI 组件
│   ├── SearchBar       # 模糊搜索
│   ├── LocationCard    # 地点卡片
│   ├── NarrativeBlock  # 核心：交汇叙事展示
│   ├── Timeline        # 时间线
│   ├── EventCard       # 事件详情卡片
│   ├── RelatedPlaces   # 相关地点推荐
│   ├── RandomDiscovery # 随机发现
│   └── Footer
├── pages/             # 页面
│   ├── HomePage        # 首页（搜索 + 推荐）
│   ├── PlacePage       # 地点详情（叙事 + 时间线）
│   └── CrossingPage    # 全部交汇故事
├── data/              # 数据层
│   ├── locations.ts    # 所有地点与事件数据
│   └── index.ts        # 搜索 + 叙事生成逻辑
└── types.ts           # 类型定义
```
